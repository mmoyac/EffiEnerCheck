# Borradores del contenido de las landings

Contenido en preparación: **no se publica**. El backend solo carga `../contenido/*.json`.

- `santa-laura.json`: versión completa de la landing de Santa Laura (comunidad, espacios,
  administración, contacto, ubicación), con los datos `[POR CONFIRMAR]` pendientes. Mientras tanto,
  `../contenido/santa-laura.json` publica solo la portada con el botón de acceso.

Para publicar una sección: completa sus datos aquí, cópiala a `../contenido/santa-laura.json`
y despliega. El backend valida el archivo al arrancar (inválido = no arranca).
